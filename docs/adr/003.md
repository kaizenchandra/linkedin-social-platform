# 003: Database ownership

Accepted 2026-09-27.

One local Oracle Free instance, three independently credentialed schemas. Flyway additive versioned migrations; no
cross-schema joins or foreign keys. Runtime DML and migration DDL credentials are separated in deployment.

MVP-2 adds independent MEDIA_APP and MESSAGING_APP schemas and DML-only runtime users. The local Oracle instance remains
shared infrastructure; there are no cross-schema business queries.
